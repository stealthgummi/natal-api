Developer Instructions

Clean 2-Endpoint REST Architecture

Integrate transparent visual overlays or pure psychological intelligence with two simple POST requests.

POST /v1/chart.svg
Returns: image/svg+xml

Generates a pure, transparent vector SVG overlay stream. Ideal for dropping directly into HTML <img> tags, mobile cards, canvas elements, or graphic design workflows.

curl -X POST "https://easy-chart-api.vercel.app/v1/chart.svg" \ -H "Content-Type: application/json" \ -d '{ "birth_data": { "date": "1994-08-18", "time": "14:15", "city": "Miami" }, "size": 800 }' \ --output my_chart.svg
const response = await fetch('https://easy-chart-api.vercel.app/v1/chart.svg', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ birth_data: { date: '1994-08-18', time: '14:15', city: 'Miami' }, size: 800 }) }); const svgMarkup = await response.text(); // Inject into DOM: document.getElementById('chart-container').innerHTML = svgMarkup;

Parameter Reference

Field Type Required Description
birth_data.date string Yes Birth date in YYYY-MM-DD format (e.g. 1971-03-02).
birth_data.time string Yes Local birth time in 24-hour HH:MM format (e.g. 13:11).
birth_data.city string Yes City name. Coordinates, IANA timezone, and historical DST are auto-resolved.
house_system string No House division method: whole_sign (default), placidus, or equal.
size number No Square pixel dimensions of the SVG canvas (default 800).
